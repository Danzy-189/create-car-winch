# Create: Car Winch — русское описание

Аддон к **Create: Aeronautics / Create: Simulated** для Minecraft 1.21.1 (NeoForge).

Добавляет три вещи:

- **лебёдку**, управляемую редстоуном, с настоящим физическим тросом;
- **фаркоп**, к которому цепляется трос;
- **сцепку**, которая соединяет два фаркопа жёстким валом Create.

Трос — это `ServerRopeStrand` из Simulated, тот же самый, что использует штатная лебёдка
Aeronautics. Сцепка — физический констрейнт Sable между двумя сублевелами.

## Лебёдка и трос

1. Поставь **лебёдку** на свою машину, а **фаркоп** — на то, что собираешься тащить.
2. ПКМ стальным тросом по лебёдке, затем по фаркопу. Shift + ПКМ — сброс выбора.
3. Лебёдка переключается на модель с намотанным барабаном, фаркоп — на модель с крюком,
   между ними появляется трос.
4. Стрижка (любой предмет из тега `destroys_rope` в Simulated) режет трос и возвращает предмет.

### Управление редстоуном

Лебёдка читает верх и низ отдельно, поэтому один блок умеет и тянуть, и травить:

| Сигнал | Поведение |
| --- | --- |
| **Сверху** (или с любого бока) | Наматывает трос. Сила сигнала задаёт скорость. |
| **Снизу** | Принудительно травит трос. Сила сигнала задаёт скорость. |
| Оба одинаковой силы | **Тормоз**: трос зафиксирован на текущей длине. |
| Нет сигнала | Свободный ход: когда трос натягивается, лебёдка травит его, чтобы можно было уехать. |

Константы настройки лежат в `CarWinchBlockEntity`: `MAX_RANGE`, `REEL_SPEED`, `RELEASE_SPEED`,
`PAYOUT_SPEED`, `SLACK_TOLERANCE`.

## Сцепка: вал Create фиксированной длины

Два фаркопа можно соединить не тросом, а **жёстким горизонтальным валом**.

1. Поставь конструкции так, чтобы фаркопы были примерно в **2 блоках** друг от друга
   и на **одной высоте**.
2. ПКМ сцепкой по первому фаркопу, затем по второму. Между ними появляется
   `create:shaft`, выложенный сегментами по одному блоку вдоль оси.
3. Shift + **гаечный ключ Create** по любому из фаркопов разбирает сцепку.

Как это работает физически:

- Длина **всегда номинальная, 2 блока** (`TowbarBlockEntity.COUPLING_LENGTH`). Якорь второго
  тела высчитывается из этой константы, а не из расстояния в момент клика, поэтому вал
  не растягивается и не сжимается.
- Соединение разрешено только если фаркопы уже стоят почти на нужном расстоянии
  (`COUPLING_LENGTH_TOLERANCE`), поэтому ничего не телепортируется в момент сцепки.
- Констрейнт блокирует `LINEAR_X/Y/Z` и `ANGULAR_Z`, оставляя свободными `ANGULAR_X/Y`:
  прицеп поворачивает влево-вправо и складывается вверх-вниз, но не крутится вокруг оси вала.
- Вал должен быть горизонтальным: перепад выше `MAX_VERTICAL_OFFSET` отклоняется.
- Оба фаркопа должны стоять на **разных** собранных конструкциях.
- Сцепка хранится в NBT. Если констрейнт стал невалиден (перезагрузка чанка, пересборка
  конструкции), он пересоздаётся — с паузой между попытками и лимитом попыток,
  после которого сцепка расходится.

При отказе игрок видит конкретную причину: неверное расстояние, не горизонтально,
не на конструкции, одна и та же конструкция или отказ физики.

## Модели и текстуры

В репозитории лежат временные модели-кубики, чтобы мод собирался и запускался сразу.

Свои модели готовь в Blockbench и сохраняй **уже в формате Minecraft JSON**
(**File → Export → Block/Item Model**). Формат `.bbmodel` игрой не читается.

Папка `1/` в корне репозитория — это источник арта. Скрипт `tools/import_models.sh`
берёт файлы оттуда локально (ничего не скачивая из интернета):

```text
1/winch.json      → assets/carwinch/models/block/winch.json
1/winch_1.json    → assets/carwinch/models/block/winch_1.json
1/towbar.json     → assets/carwinch/models/block/towbar.json
1/towbar_1.json   → assets/carwinch/models/block/towbar_1.json
1/winch.png       → assets/carwinch/textures/block/winch.png
1/winch_drum.png  → assets/carwinch/textures/block/winch_drum.png
1/towbar.png      → assets/carwinch/textures/block/towbar.png
1/winch_hook.png  → assets/carwinch/textures/block/winch_hook.png
1/iron_rope.png   → assets/carwinch/textures/item/iron_rope.png
```

JSON-модели прогоняются через `tools/fix_model.py` — он правит пути к текстурам
и приводит модель к виду, который ожидает игра.

Важное:

- Файлы с суффиксом `_1` — это состояния с крюком / намотанным барабаном.
  Сейчас `towbar.json` и `towbar_1.json` идентичны, поэтому смена состояния в игре не видна —
  скрипт импорта предупреждает об этом в логе сборки.
- Сцепке модель не нужна: рисуется штатный вал Create.
- Модели сделаны смотрящими **вверх**; повороты для остальных направлений заданы в
  `blockstates/winch.json` и `blockstates/towbar.json`.
- `tools/convert_bbmodel.py` лежит в репозитории как ручной инструмент и в сборке не участвует.

## Как получить jar через GitHub Actions

1. Открой вкладку **Actions**.
2. Выбери **Build Create Car Winch**. Сборка идёт автоматически при каждом пуше в `main`,
   а вручную — кнопкой **Run workflow**.
3. Дождись зелёной галочки. Первый запуск может идти 5-15 минут.
4. В завершённом запуске прокрути до **Artifacts** и скачай `create-car-winch-jar`.
5. Внутри будет `carwinch-1.1.0.jar`.

## Сборка локально

Нужен JDK 21 и интернет (Gradle тянет Create, Sable, Veil, Flywheel и сборку
Create: Aeronautics из Maven/Modrinth).

```bash
gradle wrapper --gradle-version 8.12   # один раз, если Gradle уже установлен
./gradlew build
```

Результат: `build/libs/carwinch-1.1.0.jar`. `./gradlew runClient` запускает дев-клиент
с Create и Aeronautics.

## Установка в Minecraft

Нужен Minecraft Java Edition 1.21.1 с NeoForge 21.1.235, Create 6.0.10 и Create: Aeronautics 1.3.0.
Положи `carwinch-1.1.0.jar` в:

```text
%appdata%\.minecraft\mods
```

Simulated отдельно не нужен: он встроен в Create: Aeronautics.

## Если сборка красная

Открой **Actions → Build Create Car Winch → Build jar**, прокрути вниз и смотри последние
30-50 строк лога. Чаще всего это несовпадение версий Create/Aeronautics/Sable или
ошибка в исходниках, а не проблема с моделями.
